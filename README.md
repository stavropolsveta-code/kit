# Эхо Древних (Echo of Ancients) — Unity-прототип

Прототип ядра 3D match-3 по GDD (версия 1.0). Собран как готовый проект Unity 6 (6000.3.2f1) + URP 17.
Открывается через **Hub → Add → путь `EchoOfAncients/`**.

## Что уже реализовано

### Логика поля (`Assets/Scripts/Core/`)
- `Board` — сетка 8×8, ячейки с фишками и препятствиями.
- `BoardGenerator` — генерация поля без готовых матчей.
- `MatchFinder` — поиск совпадений (горизонталь/вертикаль), чистый и тестируемый.
- `BoardResolver` — сердце игры:
  - свап только соседних подвижных фишек (нельзя трогать замороженные);
  - каскады (цепные реакции) до полной остановки;
  - **спец-фишки**: 4 в ряд → линия (горизонталь/вертикаль), 5 в ряд или T\L-форма → бомба (радиус 3×3);
  - **препятствия**: лёд (2 слоя, «нужно 2 матча» по GDD), скала (непробиваемая);
  - гравитация и до-заполнение поля новыми фишками.
- `LevelSession` — цели уровня (счёт/сбор/битьё льда), лимит ходов, таймер, победа/поражение.

### Мета-режим (`Assets/Scripts/Meta/`)
- `ResourceWallet` — мягкая (дерево/камень/эссенция) и твёрдая (кристалл) валюта, разблокировки.
- `BuildingDefinition` / `Building` / `City` — постройка и прокачка зданий, издержки растут с уровнем.
- `BuildingCatalog` — Ратуша, Склад, Кузница (эффект поля), Древо Жизни, Библиотека, Храм (налоги).
- Кузница/Древо пока только флаги `FieldEffect` — хук для будущих правил поля из GDD №1.3.3.

### Unity-слой (`Assets/Scripts/Unity/`)
- `BoardView` — создаёт тiles из примитивов, ввод кликом (первый клик — выбор, второй — обмен), физический рейкаст.
- `TileView` — цвета фишек, маркеры спец-фишек, визуал льда/скалы.
- `GameManager` — сборка всего, зачисление наград, **debug-HUD (OnGUI)** со счётом, ходами, ресурсами и кнопками постройки города.

## Как запустить
1. Открой проект в Unity 6 (6000.3.2f1): **Hub → Add → путь `EchoOfAncients/`**.
2. Создай пустую сцену.
3. В верхнем меню выбери **Эхо Древних → Создать демо-сцену** — автоматически появятся камера, свет, `GameManager` и `BoardView`, всё связано.
4. Нажми **Play** и играй кликами: первый клик — выбор фишки, второй — обмен.

Ручной вариант: добавь на один объект компоненты `BoardView` + `GameManager`, в поле `Board View` назначь `BoardView`.

## Заливка на Яндекс.Игры

> На этом ПК модуль **WebGL Build Support не установлен** (есть только Windows). Перед сборкой его нужно добавить.

1. **Unity Hub → Installs → «⚙» у своей версии → Add modules → отметь «WebGL Build Support» → Install.**
2. Открой проект. Пакет Яндекс SDK (`com.agava.yandexgames`) уже прописан в `Packages/manifest.json` — Unity подтянет его сам (нужен интернет и Git).
3. В проекте создай демо-сцену: **Эхо Древних → Создать демо-сцену** (или свою) и добавь её в **File → Build Settings**.
4. Сборка в один клик: **Эхо Древних → Собрать WebGL (Яндекс Игры)**. Появится `Build/WebGL/` и рядом `Build/WebGL.zip`.
5. Загрузи `Build/WebGL.zip` в консоль Яндекс.Игр (Игры → создать /**Сборка**).

Интеграция SDK (`Assets/Scripts/Yandex/YandexBridge.cs`, добавь на уровень):
- инициализация и авто-вставка SDK-скрипта в HTML;
- авторизация / запрос имени и аватара;
- **RV-реклама** (кнопка «RV-реклама» в HUD даёт +5 Янтаря);
- interstitial;
- **облачные сохранения** (синхронизация `GameSave` с аккаунтом, при старте подхват);
- лидерборд `score` (запись счёта).

Замечания:
- Пакет подключается напрямую вручную: `Window → Package Manager → + → Add package from git URL → https://github.com/forcepusher/com.agava.yandexgames.git#16.0.0`.
- SDK-скрипт вставляется в HTML сам при первом `YandexGamesSdk.Initialize()` — отдельный WebGL-шаблон не обязателен.
- Перед публикацией `Project Settings → Player → WebGL`: Compression Format часто выставляют в **Disabled** (сжатие уже делает Яндекс).

## Облачная сборка (GitHub Actions) — не грузит этот ноутбук

На этом ПК (2,9 ГБ ОЗУ) локальная WebGL-сборка роняет систему. Готов пайплайн, который собирает игру **в облаке GitHub** (раннеры 7 ГБ ОЗУ).

Файлы уже в проекте: `.github/workflows/activation.yml`, `.github/workflows/build-webgl.yml`, `.gitignore`.

### Шаги (один раз)
1. Создай репозиторий на GitHub (Public, чтобы минуты были бесплатными).
2. Залей в него **содержимое папки `EchoOfAncients/`** (Assets, Packages, ProjectSettings, .gitignore, .github) — например, через `Upload files` в веб-интерфейсе.
3. В репозитории: **Actions → Get Unity License → Run workflow** → скачай артефакт `Unity_v6000.3.2f1.alf`.
4. Открой https://license.unity3d.com , загрузи туда `.alf` → получишь файл `Unity_v6000.3.2f1.ulf` → скачай его.
5. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**: имя `UNITY_LICENSE`, значение — **всё содержимое** `.ulf` (целиком).
6. Запусти **Build WebGL (Yandex)** → подожди 15–40 минут → скачай артефакт `WebGL-build` → внутри лежит `webgl-build.zip` — его загружаешь в консоль Яндекс.Игр.

Сборка в облаке использует `BuildForCI()` из `Assets/Scripts/Editor/WebGLBuilder.cs` (создаёт сцену, собирает WebGL, при ошибке падает с кодом ≠ 0).

## Проверка кода (без открытия Unity)
Ядро (`Core/`, `Meta/`) и Unity-слой компилируются и проверяются тестами через бандльный компилятор Unity:
- смоук-тест `echo_check/Harness.cs` — каскады, спец-фишки, лёд, отклонение невалидного свапа (7/7 проходят).

## Ограничения этой итерации
- Визуал — цветные кубы (плейсхолдеры), не PBR/lightmapping.
- `FieldEffect` зданий на правила поля ещё не расписан.
- Нет SDK Яндекса, уровня, сохранений.
- Спец-фишка создаётся, но совмещение двух спец-фишек (`бомба+линия`) ещё не обработано.

## Основная механика спец-фишек (для отладки)
- Собери **4 в один ряд** → авто-линия.
- Собери **5 в ряд** или **T/L-форму** → бомба 3×3.
- Совпадение, в которое входит спец-фишка, взрывает её эффект.
